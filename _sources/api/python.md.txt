# kangengine

KangEngine's Python API is split into two layers:

- Native bindings exposed through public package paths, such as `ke.App`,
  `ke.render.Renderer`, `ke.scene.Prim`, `ke.asset.FBXLoader`, and
  `ke.physics.PhysicsWorld`.
- Pure Python workflow helpers, such as `ke.sim.KangSimWorld`,
  `ke.visual.sim.SimWorldVisualizer`, `ke.motion_module.MotionEditor`, and
  utility modules.
